01 / KẾT NỐI TIKTOK LIVE

Đưa khán giả lên xe

Tự thử lại sau 2 phút khi mất kết nối.

EulerStream API key

Tạo file .env bên cạnh package.json, thêm EULERSTREAM_API_KEY=key_cua_ban rồi chạy lại. Key chỉ nằm trên server.

Thả tim hoặc bình luận để lên xe, hoặc trả lời A / B / C / D để vừa tham gia vừa chốt đáp án. Đúng nhận nitro 5 giây. Bình luận trái / phải đổi làn; NITRO để dùng 30% năng lượng.
